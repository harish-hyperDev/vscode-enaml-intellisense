# Enaml Syntax Highlighting

Syntax highlighting and editor support for **Enaml** and [Enaml-Web](https://github.com/codelv/enaml-web) in **VS Code** and **VSCodium**.

## Features

- Enaml syntax highlighting, including embedded Python expressions.
- Comment commands, bracket and quote pairing, indentation, and folding.
- Support for `.enaml` files and the **Enaml** language mode.

This release provides editor syntax support only; language-server features are introduced in version 0.2.0.
